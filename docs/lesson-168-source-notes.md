## Textbook structure

The Merzlyak grade-5 textbook contents identify **§24 as «Комбинаторные задачи»**. The core §24 exercise block is the combinatorics section, whereas §12 belongs to the angle block.

Reference for textbook contents:
https://www.at.alleng.org/d/math/math1370.htm

Therefore lesson 168 is treated as the **second consecutive combinatorics review lesson under §24**. It intentionally advances beyond lesson 167 rather than repeating the same introductory tasks.

## Pedagogical scope

Lesson 167 covered the base toolkit:
- systematic enumeration;
- rule of product;
- rule of sum;
- order matters / does not matter;
- simple restrictions;
- repetition allowed / forbidden.

Lesson 168 raises the difficulty through:
- splitting into non-overlapping cases;
- complement counting for «at least one»;
- constraints on first/last positions;
- zero in multidigit numbers;
- mandatory elements;
- avoiding overcounting;
- symmetry arguments;
- multi-step choices with one or more forbidden combinations.
