## Точная контрольная работа

Используется **контрольная работа №8 «Умножение и деление десятичных дробей», вариант 1** из методического пособия без замены чисел и без изменения формулировок.

1. Вычислите:
   1. `0,024 · 4,5` → `0,108`;
   2. `29,41 · 1 000` → `29410`;
   3. `2,86 : 100` → `0,0286`;
   4. `4 : 16` → `0,25`;
   5. `0,48 : 0,8` → `0,6`;
   6. `9,1 : 0,07` → `130`.
2. `(4 − 2,6) · 4,3 + 1,08 : 1,2` → `6,92`.
3. `2,4(x + 0,98) = 4,08` → `x = 0,72`.
4. Лодка: 1,4 ч по течению, 2,2 ч против течения, собственная скорость 19,8 км/ч, течение 1,7 км/ч → общий путь `69,92 км`.
5. Перенос запятой вправо через одну цифру увеличивает дробь на 14,31 → исходная дробь `1,59`.

Итого: **5 заданий / 10 проверяемых ответов**.

## Режим контроля

Контрольная повторяет защитный контракт урока 125:

- ответы, решения, подсказки и mentor UI скрыты до первичной сдачи;
- до сдачи разрешено возвращаться и менять ответы;
- первичный результат фиксируется как неизменяемый snapshot;
- после сдачи показываются правильные ответы и решения;
- отдельный режим коррекции позволяет исправить только ошибочные поля;
- коррекция не изменяет первичный балл;
- прогресс и результат сохраняются в `localStorage`;
- десятичные ответы сравниваются канонически и строго, без floating tolerance.
