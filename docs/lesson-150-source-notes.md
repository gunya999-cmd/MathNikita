## Exact textbook anchors

### №1094
Найдите число, если:
1) 1% этого числа равен 7;
2) 1% этого числа равен 0,36;
3) 12% этого числа равны 4,8;
4) 104% этого числа равны 260.

Calculations:
- 7 / 0.01 = 700
- 0.36 / 0.01 = 36
- 4.8 / 0.12 = 40
- 260 / 1.04 = 250

Answers: 700; 36; 40; 250.

### №1096
Михаил купил справочник по математике, потратив на него 45% имевшихся у него денег. Сколько денег было у Михаила, если справочник стоит 36 р.?

Calculation:
- 45% = 0.45
- 36 / 0.45 = 80

Answer: 80 rubles.

Reference for the older-edition wording:
- https://otvetkin.info/reshebniki/5-klass/matematika/merzlyak/nomer-1096

### №1117 (1, 2)
Решите уравнение:
1) 0,31x + 1,2 = 1,2124;
2) 0,5x − 17 = 40,52.

Calculations:
- 0.31x = 0.0124; x = 0.04
- 0.5x = 57.52; x = 115.04

Answers: 0.04; 115.04.

## Lesson design boundary

Lesson 150 introduces the inverse percent model: if p% of an unknown whole equals a known part b, then the whole is b / (p / 100). The lesson emphasizes identifying the 100% base, using either division by the decimal multiplier or the 1%-then-100% method, and checking by taking the stated percentage of the recovered whole. Later §38 lessons will deepen composite word problems; lesson 150 stays focused on the foundational inverse model.
