# 01. Продуктовая концепция

## 1.1. Для кого создаётся продукт

Первая версия предназначена для ученика 5 класса, который должен уверенно освоить школьную программу и постепенно перейти к олимпиадному стилю мышления. Продукт также должен быть понятен родителю без педагогической подготовки.

## 1.2. Основной пользовательский сценарий

Ребёнок открывает приложение и видит один главный призыв: **«Продолжить путешествие»**.

Приложение уже знает:

- текущий урок по годовому плану;
- текущий параграф и раздел;
- какие навыки требуют повторения;
- какие задания можно пропустить из-за устойчивого освоения;
- какую олимпиадную идею дать сегодня;
- сколько уроков пройдено и осталось.

После нажатия начинается занятие. Выбор темы, номера урока и сложности ребёнку не предлагается.

## 1.3. Экран ученика

На главном экране отображаются:

- «Урок 17 из 175»;
- номер параграфа;
- название темы;
- короткая цель урока;
- примерная длительность;
- прогресс учебного года;
- Кот Пифагор в текущей игровой локации;
- одна основная кнопка.

Дополнительные экраны доступны, но не конкурируют с главной кнопкой:

- карта знаний;
- коллекция математических идей;
- достижения мира;
- профиль кота;
- родительский кабинет под отдельным входом.

## 1.4. Учебное обещание

Продукт обещает не просто выполнение школьной программы. К концу года ученик должен:

- понимать, а не только воспроизводить правила;
- уверенно выполнять базовые вычисления;
- переводить текст задачи в математическую модель;
- объяснять ход решения;
- находить и исправлять ошибки;
- знать несколько способов решения;
- владеть базовыми олимпиадными приёмами;
- не бояться незнакомых задач.

## 1.5. Роль учебника

Годовой порядок тем строится по школьной программе и методическим материалам. При этом одно занятие может использовать:

- наиболее ясное объяснение одного автора;
- наиболее удачную визуальную модель другого;
- тренировочные задания третьего;
- нестандартную задачу из кружковых материалов;
- контрольный формат из дидактического пособия.

Ребёнок видит единый курс, а не набор разных учебников.

## 1.6. Что продукт не должен делать

- Не показывать каталог из сотен уроков как основной экран.
- Не заставлять ребёнка самостоятельно выбирать слабую тему.
- Не выдавать бесконечные однотипные примеры.
- Не наказывать за ошибку потерей игрового прогресса.
- Не маскировать отсутствие методики яркими эффектами.
- Не усложнять задания только увеличением чисел.
- Не превращать олимпиадную математику в случайные «задачи со звёздочкой».

## 1.7. Роль родителя

Родитель получает отдельный обзор:

- текущая позиция в годовом плане;
- темп относительно программы;
- освоенные и нестабильные навыки;
- повторяющиеся типы ошибок;
- результаты проверочных и контрольных;
- динамика самостоятельности;
- использование подсказок;
- рекомендации без необходимости вручную назначать уроки.

## 1.8. Критерий успеха занятия

Занятие считается успешным, когда одновременно выполнены три условия:

1. Ребёнок продвинулся по программе или укрепил необходимый пробел.
2. Система получила новые достоверные данные о знаниях.
3. Ребёнок завершил занятие без ощущения наказания и понимает, куда движется дальше.

## 1.9. Критерий успеха учебного года

Курс завершён качественно, если ученик:

- прошёл все обязательные темы;
- подтвердил ключевые навыки контрольными точками;
- закрыл критические пробелы предыдущих классов;
- собрал базовую коллекцию олимпиадных методов;
- способен решать смешанные задачи без подсказки на выбор темы;
- сохранил интерес к продолжению курса.
