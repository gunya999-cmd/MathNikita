Педагогический смысл первого урока §36: определить среднее арифметическое, научиться находить его для нескольких чисел и перейти к средним значениям величин, прежде всего средней скорости и средней урожайности.

## Точные задания учебника

### №1034

Найдите среднее арифметическое чисел:

1. `4,2` и `2,1` → `(4,2+2,1):2 = 3,15`;
2. `3,9; 6; 9,18; 15,8` → сумма `34,88`, среднее `8,72`.

### №1038

1. Автомобиль ехал 3 ч со скоростью 56,4 км/ч и 4 ч со скоростью 62,7 км/ч. Общий путь `420 км`, общее время `7 ч`, средняя скорость `60 км/ч`.
2. С 30 га получили по 30,2 ц/га, с 20 га — по 32,3 ц/га. Общий урожай `1552 ц`, площадь `50 га`, средняя урожайность `31,04 ц/га`.

### №1052 (1)

Цепочка:

- `9,88 : a = 3,8` → `a=2,6`;
- `3,8 − b = 1,74` → `b=2,06`;
- `1,74 · c = 6,09` → `c=3,5`.

## Теория урока

Вопрос 1 §36: что называют средним арифметическим нескольких чисел.

Рабочее правило урока:

`среднее арифметическое = сумма всех чисел : количество чисел`.

Для средней величины используется более общий смысл:

`среднее значение = общий результат : общий объём`.

Для движения:

`средняя скорость = весь путь : всё время`.

Отдельно фиксируется типичная ошибка: при разных временах движения нельзя автоматически брать полусумму скоростей.
