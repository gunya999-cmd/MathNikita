## Exact textbook anchors

### №1003 (3–4)
Solve equations:
- `9,3 − 0,14x = 8,95` → `x = 2,5`;
- `8,6x − 6,9x + 0,49 = 1` → `x = 0,3`.

### №1018
Серенький: `65,34 кг` за `5,4 ч`; Беленький: `76,32 кг` за `7,2 ч`.
- `65,34 : 5,4 = 12,1 кг/ч`;
- `76,32 : 7,2 = 10,6 кг/ч`;
- difference `12,1 − 10,6 = 1,5 кг/ч`;
- Серенький has the higher productivity.

### №1027
If moving the decimal comma one digit to the right increases the number by `62,01`, let the original number be `x`:
- new number `10x`;
- `10x − x = 62,01`;
- `9x = 62,01`;
- `x = 6,89`.

## Pedagogical focus

Lesson 141 is a synthesis lesson rather than a new division rule. It consolidates:
- equations with decimal coefficients and like terms;
- unknown factor/divisor via inverse operations;
- productivity as work divided by time;
- comparison on a common per-unit basis;
- decimal-shift modelling with `10x−x` and `100x−x`;
- mixed decimal division applications;
- systematic answer checking before control work №8.
