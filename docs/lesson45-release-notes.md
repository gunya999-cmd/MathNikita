# Lesson 45 release scope

Lesson 45 is the second lesson of §13 «Многоугольники. Равные фигуры» and is implemented as consolidation rather than a second introduction.

Release contract:
- 36 main stages;
- real SVG polygon construction with self-intersection validation;
- side/diagonal distinction;
- derivation and application of `n − 3` and `n(n − 3) / 2`;
- perimeter and reverse perimeter problems;
- equality by superposition;
- 20 mandatory curated practice tasks;
- Sulafat stage/practice narration and stale-audio interruption;
- iPad/WebKit geometry hard-tests;
- Course 1–45 certification before merge.
