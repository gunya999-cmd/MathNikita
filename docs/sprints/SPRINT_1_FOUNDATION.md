# Sprint 1 — фундамент учебного года

## Цель

Перевести приложение с демонстрационного плана на реальный годовой маршрут 5 класса из 175 уроков и подготовить устойчивую основу для дальнейшего наполнения.

## Сделано

- введён полный план из 175 последовательных уроков;
- сохранены главы и параграфы базовой линии Мерзляка;
- отдельно отмечены уроки нового материала, повторения, контроля и итоговой аттестации;
- каждый многоурочный параграф разбит на последовательные этапы: открытие, базовые способы, практика, углубление, задачи, закрепление и проверка;
- сохранена совместимость с текущими экранами прогресса и карты знаний;
- первые три урока остаются доступными как рабочий контент, остальные образуют проверяемый каркас наполнения.

## Следующие задачи спринта

1. Связать каждый элемент годового плана с отдельной записью урока в движке.
2. Исключить циклическое повторение первых трёх демонстрационных уроков.
3. Добавить паспорт микронавыков для главы 1.
4. Перестроить карту знаний: показывать районы и ближайшие уроки, а не 175 одинаковых карточек.
5. Добавить контроль готовности контента перед открытием урока ученику.
6. Наполнить уроки 1–20 по главе «Натуральные числа».

## Критерии готовности

- production-сборка проходит в GitHub Actions;
- `yearPlan.length === 175`;
- номера уроков непрерывны от 1 до 175;
- ребёнок видит точный номер урока, параграф, тему, пройденное и оставшееся количество;
- незаполненный урок не подменяется заданием из другой темы;
- стабильная версия публикуется через GitHub Actions в Cloudflare.
