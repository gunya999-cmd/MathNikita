# MathNikita — базовый план 5 класса на 175 уроков

Статус: **методический каркас**.

Основа: примерное тематическое планирование линии Мерзляка для режима 5 часов в неделю. План сохраняет школьную последовательность и номера параграфов. Внутри каждого урока приложение добавит собственные интерактивы, повторение и олимпиадную задачу.

# Как превратить диапазоны в отдельные уроки приложения

Каждый диапазон разбивается на конкретные уроки. Например, § 1 занимает два школьных часа:

- Урок 1. Натуральные числа и натуральный ряд.
- Урок 2. Предыдущее и последующее число. Закрепление и мини-контроль.

§ 3 занимает четыре часа:

- Урок 6. Отрезок и его обозначение.
- Урок 7. Измерение длины.
- Урок 8. Единицы длины и перевод величин.
- Урок 9. Практическая работа и контроль навыка.

Для каждого из 175 уроков будут заполнены поля:

- номер;
- параграф;
- название;
- тип урока;
- цель;
- новые понятия;
- предварительные навыки;
- микронавыки;
- объяснение;
- набор практики;
- типичные ошибки;
- коррекционный блок;
- олимпиадный метод;
- контроль;
- анимация;
- объект на карте;
- награда кота Пифагора.

# Правило адаптации календаря

Основной номер урока не меняется. Дополнительные коррекционные задания вставляются **внутрь текущего занятия** или как короткий блок перед следующим уроком.

Пример:

- по календарю сегодня урок 39;
- обнаружен пробел по измерению углов;
- приложение добавляет 5-минутное повторение из уроков 37–38;
- затем ребёнок проходит урок 39 по плану;
- контроль навыка повторяется на уроке 41.

Если пробел критически мешает новой теме, создаётся коррекционный мини-урок `39R`, но годовой счётчик остаётся на уроке 39 до его завершения.
